# 3D model attribution

The MacBook GLB files in this folder are adapted from:

- Title: macbook pro M3 16 inch 2024
- Author: jackbaeten (https://sketchfab.com/jackbaeten)
- Source: https://sketchfab.com/3d-models/macbook-pro-m3-16-inch-2024-8e34fc2b303144f78490007d91ff57c4
- License: CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/)

The same title, author, source, and licence are embedded in each GLB (`asset.extras`) and in the gltfjsx headers for `Macbook-14.jsx`, `Macbook-16.jsx`, and `Macbook.jsx`. The files were converted with gltfjsx (`-T`). Changes were made to load them in this page; the 14-inch and 16-inch views use the converted assets at different scales.
